# Resource Grid Overlay

**La grille des ressources se trouve désormais dans Map Editor Improvements** (à partir de la
version 1.0.65), dans son groupe de paramètres « Grille des ressources ». Utilisez ce module à
la place de celui-ci. Tant que les deux sont activés, Map Editor Improvements laisse la grille à
ce module. Les paramètres ne sont pas repris : si vous aviez modifié les paramètres de ce
module, réglez-les de nouveau là-bas.

Affiche la grille des ressources de l'IA, les limites de rotation des châteaux et l'emprise des mines de fer pour aider à créer des cartes.
