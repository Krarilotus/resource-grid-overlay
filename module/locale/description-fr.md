# Resource Grid Overlay

**Map Editor Improvements inclut cette grille des ressources**, dans son groupe de paramètres « Grille des ressources ». Utilisez ce module à la place de celui-ci. Tant que les deux sont activés, Map Editor Improvements laisse la grille à ce module.

Dessine la grille des ressources de l'IA par-dessus le terrain dans l'éditeur de cartes. **Alt + G** permet de l'activer et de la désactiver.
