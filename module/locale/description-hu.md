# Resource Grid Overlay

**A nyersanyagrács mostantól a Map Editor Improvements modulban található** (az 1.0.65-ös
verziótól), annak „Nyersanyagrács” beállításcsoportjában. Ehelyett azt a modult használd. Amíg
mindkettő be van kapcsolva, a Map Editor Improvements átengedi a rácsot ennek a modulnak. A
beállítások nem kerülnek átvételre: ha módosítottad ennek a modulnak a beállításait, ott állítsd
be őket újra.

Megmutatja az MI nyersanyagrácsát, a várforgatási határokat és a vasbánya helyét a térképszerkesztéshez.
