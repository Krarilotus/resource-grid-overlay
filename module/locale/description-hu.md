# Resource Grid Overlay

**A Map Editor Improvements tartalmazza ezt a nyersanyagrácsot**, a „Nyersanyagrács” beállításcsoportjában. Ehelyett azt a modult használd. Amíg mindkettő be van kapcsolva, a Map Editor Improvements átengedi a rácsot ennek a modulnak.

Kirajzolja az MI nyersanyagrácsát a terep fölé a térképszerkesztőben. Az **Alt + G** ki- és bekapcsolja.
