# Resource Grid Overlay

**Map Editor Improvements incluye esta cuadrícula de recursos**, en su grupo de ajustes «Cuadrícula de recursos». Usa ese módulo en lugar de este. Mientras ambos estén activados, Map Editor Improvements deja la cuadrícula a este módulo.

Dibuja la cuadrícula de recursos de la IA sobre el terreno en el editor de mapas. **Alt + G** la activa y desactiva.
