# Resource Grid Overlay

**La cuadrícula de recursos ahora está en Map Editor Improvements** (desde la versión 1.0.65),
en su grupo de ajustes «Cuadrícula de recursos». Usa ese módulo en lugar de este. Mientras ambos
estén activados, Map Editor Improvements deja la cuadrícula a este módulo. Los ajustes no se
transfieren: si cambiaste los ajustes de este módulo, configúralos de nuevo allí.

Muestra la cuadrícula de recursos de la IA, los límites de rotación de castillos y la superficie de las minas para editar mapas.
