# Resource Grid Overlay

**Map Editor Improvements enthält dieses Ressourcenraster**, in seiner Einstellungsgruppe „Ressourcenraster“. Verwende stattdessen jenes Modul. Solange beide aktiviert sind, überlässt Map Editor Improvements das Raster diesem Modul.

Zeichnet das Ressourcenraster der KI über das Gelände im Karteneditor. **Alt + G** schaltet es ein und aus.
