# Resource Grid Overlay

**Das Ressourcenraster befindet sich jetzt in Map Editor Improvements** (ab Version 1.0.65), in
der Einstellungsgruppe „Ressourcenraster“. Verwende stattdessen jenes Modul. Solange beide
aktiviert sind, überlässt Map Editor Improvements das Raster diesem Modul. Einstellungen werden
nicht übernommen: Wenn du die Einstellungen dieses Moduls geändert hast, stelle sie dort neu
ein.

Zeigt Ressourcenraster der KI, Grenzen der Burgdrehung und Grundflächen von Eisenminen als Hilfe beim Platzieren von Ressourcen im Karteneditor.
