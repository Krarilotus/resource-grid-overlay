# Resource Grid Overlay

**شبکه منابع اکنون در Map Editor Improvements قرار دارد** (از نسخهٔ 1.0.65)، در گروه تنظیمات «شبکه منابع» آن. به‌جای این ماژول از آن استفاده کنید. تا زمانی که هر دو روشن باشند، Map Editor Improvements شبکه را به این ماژول واگذار می‌کند. تنظیمات منتقل نمی‌شوند: اگر تنظیمات این ماژول را تغییر داده‌اید، آن‌ها را دوباره آنجا تنظیم کنید.

شبکه منابع هوش مصنوعی، مرزهای چرخش قلعه و جای معدن آهن را برای چیدمان منابع در ویرایشگر نقشه نشان می‌دهد.
