# Resource Grid Overlay

**Map Editor Improvements این شبکه منابع را در بر دارد**، در گروه تنظیمات «شبکه منابع» خود. به‌جای این ماژول از آن استفاده کنید. تا زمانی که هر دو روشن باشند، Map Editor Improvements شبکه را به این ماژول واگذار می‌کند.

در ویرایشگر نقشه می‌توانید با **Alt + G** شبکهٔ منابع هوش مصنوعی، مرزهای چرخش قلعه و جای معدن آهن را روی زمین نمایش دهید یا پنهان کنید.
