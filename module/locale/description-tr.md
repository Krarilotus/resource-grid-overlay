# Resource Grid Overlay

**Map Editor Improvements bu kaynak ızgarasını içerir**, «Kaynak ızgarası» ayar grubunda. Bu modül yerine onu kullanın. İkisi birden açıkken Map Editor Improvements ızgarayı bu modüle bırakır.

Harita düzenleyicide arazinin üzerine yapay zekânın kaynak ızgarasını çizer. **Alt + G** ile açılıp kapatılır.
