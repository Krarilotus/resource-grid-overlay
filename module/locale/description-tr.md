# Resource Grid Overlay

**Kaynak ızgarası artık Map Editor Improvements içinde yer alıyor** (1.0.65 sürümünden
itibaren), «Kaynak ızgarası» ayar grubunda. Bu modül yerine onu kullanın. İkisi birden açıkken
Map Editor Improvements ızgarayı bu modüle bırakır. Ayarlar devralınmaz: bu modülün ayarlarını
değiştirdiyseniz orada yeniden ayarlayın.

Harita düzenleyicide kaynak yerleşimine yardımcı olmak için yapay zekânın kaynak ızgarasını, kale dönüş sınırlarını ve demir madeni alanını gösterir.
