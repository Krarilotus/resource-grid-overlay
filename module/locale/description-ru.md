# Resource Grid Overlay

**Map Editor Improvements включает эту сетку ресурсов**, в своей группе настроек «Сетка ресурсов». Используйте тот модуль вместо этого. Пока включены оба модуля, Map Editor Improvements уступает сетку этому модулю.

Отображает сетку ресурсов ИИ поверх рельефа в редакторе карт. **Alt + G** включает и выключает её.
