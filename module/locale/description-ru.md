# Resource Grid Overlay

**Сетка ресурсов теперь находится в Map Editor Improvements** (начиная с версии 1.0.65), в его
группе настроек «Сетка ресурсов». Используйте тот модуль вместо этого. Пока включены оба
модуля, Map Editor Improvements уступает сетку этому модулю. Настройки не переносятся: если вы
меняли настройки этого модуля, задайте их там заново.

Показывает сетку ресурсов ИИ, границы поворота замка и площадь железного рудника для размещения ресурсов в редакторе карт.
